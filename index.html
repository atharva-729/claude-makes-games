Claude makes games

Experiments in how far AI coding models get when building games on their own. Each game was written start to finish by an AI agent from a single prompt, with no human-written code or assets. Everything, including art and music, is generated in code.

Keyboard required. Best played on desktop. Click a game to play.
Every game is exactly as its model wrote it, apart from the later fixes listed in the changelog (so far, only to the two boss-fight games' controls).

Changelog: what was changed after the AI runs

For research purposes, the original output of each run is kept as is. A later change is made only to fix a playability problem found in play-testing. Each change is listed here, says who made it, and leaves the original code in the git history.

23 Nov 2026post-run fix · WICKFALL and GLOAMREACH

Why: in play-testing, the pogo (a down-slash in mid-air) was nearly impossible. It meant holding S and pressing X at the same time, two neighbouring keys under the same left hand. The invincibility and skip-to-boss keys also existed but appeared nowhere on screen.

Who: requested by the author and implemented by Claude Opus 5.5 in a separate session. It is not part of either model's original run.

ActionBeforeNow (default)
Move / aimArrows or WASDWASD (arrows still work)
JumpSpace or ZSpace
SlashX or JJ
DashC, K or ShiftK or Shift
BoltV or LL
Heal (hold)F;
  • New default layout: the left hand moves and the right hand acts, so a pogo is now S + J. J, K and L already worked as second keys; they are now the only ones, and the left-hand action keys (Z, X, C, V, F) have been removed so they can't clash with movement. Ctrl is deliberately not used, because Ctrl+W and Ctrl+S trigger browser shortcuts.
  • Remappable keys: press O (or the "Change controls" button) on the title or pause screen to rebind any action. Choosing a key that's already in use swaps the two actions. Bindings are saved in the browser, and "Reset to defaults" restores the layout above.
  • Testing keys on screen: the title and pause screens now list F1 (invincibility on/off) and F2 (skip to the boss). Both keys were written by the models during their runs as debug aids, but neither game ever showed them.
  • "Stuck?" hint: a line at the bottom of the screen suggests F1 (and F2 outside the boss fight) when any of these is true: you have died 3 or more times (shown for 9 s after each respawn); you have played 75 s without reaching a new part of the map; or a boss fight has lasted over 2.5 minutes. It hides once invincibility is on. These are simple timers and counters, with no pathfinding.
  • Key names that follow your bindings: the controls list and the in-world tutorial signs now name whatever keys are currently bound, instead of fixed text such as "X to slash".
  • Unchanged: physics, levels, enemies, boss, art, audio and the round-1 games. GLOAMREACH's 31 built-in self-checks still pass.
  • Code: one new file, js/controls.js, identical in both games, plus small edits where each game reads keys and draws its controls list and signs. The exact diff is in the commit history.
